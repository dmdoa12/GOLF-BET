# 골프 정산

골프 스코어와 내기(스트로크 · 뽑기) 정산을 계산하는 홈 화면 웹앱(PWA)입니다.
기록은 각자 휴대폰에만 저장되고 서버로 보내지 않습니다.

## 설치

1. 휴대폰에서 https://dmdoa12.github.io/golf-bet/ 을 엽니다.
   - 아이폰: Safari로 열고 공유 버튼 → "홈 화면에 추가"
   - 안드로이드: Chrome으로 열고 메뉴 → "앱 설치" 또는 "홈 화면에 추가"
2. 홈 화면의 "골프 정산" 아이콘으로 실행합니다. 한 번 열고 나면 인터넷 없이도 실행됩니다.

## 기능

- 시작 화면 → 모드 선택(설명 보기) → 게임 설정 → 라운드 진행 → 라운드 종료 시 날짜별 기록 저장
- 내기 방식: 스트로크(2~4명), 뽑기(4명, 스틱 뽑기 · 조커 · 개인별 판돈 · 홀별 상금 · 이월), 스킨스(2~4명, 단독 1등 독식 · 이월), 라스베가스(4명, 1·4등 vs 2·3등 편 타수 합), 후세인(4명, 직전 홀 2등 × 3 vs 나머지 3명)
- 버디 · 롱기 · 니어 보너스, OB · 벙커 · 해저드 벌금(공금), OECD 룰(3퍼트, 트리플 이상, 한 홀 최대 벌금)
- 코스: 홀별 파를 직접 입력(다음 라운드에도 이어 씀), 더블파 상한, 정산(최소 송금) 목록
- 기록 파일 내보내기 / 불러오기(진행 중 라운드 + 라운드 기록), 라운드 중 화면 꺼짐 방지

## 파일

- `index.html` 앱 본체, `sw.js` 오프라인용 서비스 워커, `manifest.webmanifest` 앱 정보, `icons/` 아이콘
- 앱을 고친 뒤에는 `sw.js`의 `VERSION`을 올려야 휴대폰에서 새 버전으로 바뀝니다.
